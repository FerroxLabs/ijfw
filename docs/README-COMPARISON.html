★ Honesty guardrails (for the README copy)

  • Voice: claim "drafts in your voice using your own writing", NOT "indistinguishable." IJFW few-shots samples of your own real writing (default-off, visible, forgettable); it does not pass an authorship-verification bar and must never imply it does.
  • Don't say "never leaves the machine." Say "stored locally, every disclosure logged, forgettable." Once it injects into a cloud tool it's disclosed — still the most private option here.
  • Frame the hosts as "works with," never "vs." They're the surfaces IJFW unifies, not competitors.
  • Only list cross-tool clients we verified inject; benchmark numbers carry the standing-limitation caveat.

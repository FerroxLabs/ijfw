# IJFW command index

Show the IJFW command map for Codex. Use this when the user types /ijfw or asks what IJFW can do. Mention that Codex 0.130 does not support third-party slash-command execution directly; these command files are installed for parity/future support. Reliable invocation today is /use <skill> or ijfw <command>.

Map:
- /cross-audit -> use skill ijfw-cross-audit or run `ijfw cross audit <target>`
- /cross-critique -> use skill ijfw-cross-audit with critique mode or run `ijfw cross critique <target>`
- /cross-research -> use skill ijfw-cross-audit with research mode or run `ijfw cross research <topic>`
- /workflow -> use skill ijfw-workflow
- /team -> use skill ijfw-team or run `ijfw team init`
- /status -> use skill ijfw-status or run `ijfw status`
- /doctor -> use skill ijfw-doctor or run `ijfw doctor`
- /handoff -> use skill ijfw-handoff
- /compress -> use skill ijfw-compress
- /memory-audit -> use skill ijfw-memory-audit
- /metrics -> run `ijfw metrics` if available, otherwise use ijfw-status.

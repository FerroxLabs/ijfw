# Run IJFW Trident cross-audit

Use the ijfw-cross-audit skill. If a target is provided, run `ijfw cross audit <target>` or equivalent tool-backed audit. If no target is provided, inspect git state and pick staged changes, unstaged changes, or last commit in that order. Return findings by severity and cite files/lines.

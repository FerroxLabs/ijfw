# Landing Page Brief: [page name or URL slug]

> Domain: `landing-page` -- a single page with a single job. If it has more
> than one CTA competing for the click, it isn't a landing page yet.

## Product

What is being offered on this page?

- **Name:** [product / offer]
- **Category:** [SaaS / course / waitlist / lead magnet / event / app download / etc.]
- **Price / commitment:** [$N / free / email-only / N minutes of attention]

One-sentence pitch from the visitor's perspective:
[pitch -- e.g., "Cut your Stripe reconciliation time from 4 hours to 4 minutes."]

## Target visitor

Be sharp. A landing page that works for everyone works for no one.

- **Who:** [role, context, life situation]
- **What they were doing 30 seconds before landing:** [scrolling X, clicked Y ad, googled Z]
- **What they already believe is true:** [pre-existing belief the page can lean on]
- **What they fear is true about this offer:** [the objection driving bounce]

## Promise

The headline-level commitment. What changes for the visitor if they say yes?

- **Promise:** [outcome in their words, not features in ours]
- **Time horizon:** [how soon they'll experience it]
- **Reversibility:** [what happens if it doesn't work for them]

## Proof

Why should the visitor believe the promise?

- **Social proof:** [logos / testimonials / counts -- specific names beat generic numbers]
- **Demonstration:** [screenshot / video / live demo / sample output]
- **Authority:** [press / certifications / founder credibility]
- **Data:** [the one number that, if true, makes the offer obvious]

## Objection handling

3-5 reasons the visitor will hesitate, and the on-page answer for each.

| Objection | Answer on page | Where it lives (above/below fold) |
|---|---|---|
| [too expensive] | [ROI framing or comparison] | [section] |
| [won't work for me] | [specific case study] | [section] |
| [will take too long to set up] | [time-to-value claim] | [section] |

## Single CTA

ONE. If you need two, you have two pages.

- **Primary CTA:** [verb -- e.g., "Start free 14-day trial"]
- **Destination:** [URL / form / checkout]
- **Friction:** [N fields, N clicks to convert]
- **Soft CTA for not-ready (optional):** [email capture / save for later -- must not dilute primary]

## Above-fold structure

What is visible without scrolling on a 720px-tall laptop?

1. [headline]
2. [subhead / one-line clarifier]
3. [primary CTA]
4. [proof element -- logos / hero image / counter / preview]

## Mobile-first constraints

- **Single column at <768px.** No horizontal scroll, ever.
- **Tap targets ≥44px.** CTAs above the fold on the smallest target device.
- **No autoplay video with sound.** No layout shift after first paint.
- **Performance budget:** [target LCP <2.5s, page weight <[N]KB]

## Done When

- [ ] A first-time visitor can state the promise back after 5 seconds on the page.
- [ ] The primary CTA is the only call-to-action above the fold on mobile and desktop.
- [ ] All listed objections are explicitly addressed somewhere on the page.
- [ ] Performance budget is met (LCP, layout shift, weight) on a throttled mobile run.
- [ ] Conversion rate is measured against a baseline target: [target %].
